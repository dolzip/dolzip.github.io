01 / DOLZIP

기능

01

멀티코어의 속도

지원하는 형식과 데이터 구조에 맞춰 여러 코어로 빠르게 압축을 풉니다.

02

익숙한 형식부터 드문 형식까지

ZIP, 7z, RAR, EGG, ALZ와 다양한 디스크 이미지를 한곳에서 엽니다.

03

암호로 보호된 파일

지원하는 암호화 형식의 파일을 암호를 입력해 안전하게 풉니다.

04

분할 압축도 한 번에

모든 조각을 같은 폴더에 두세요. 연결된 볼륨을 자동으로 찾습니다.

05

미리보기와 편집

유료 Dolzip에서 내용을 살펴보고 지원하는 압축 파일을 편집하세요.

06

dz CLI

무료 dz CLI로 목록 보기, 풀기, 만들기, 검사를 자동화하세요.

$ dz x archive.zip

02 / ZIP → ZPAQ

지원 형식
