## Website

31 languages, one shared HTML template, and no runtime dependencies. Python 3.9+ builds the site using only its standard library.

- `site/templates/page.html` — shared locale page; `index.html` — bilingual language home.
- `site/i18n/<lang>.json` — plain-text translations, escaped when rendered. Every locale must have the same keys; missing, extra, empty or duplicate entries fail the build.
- `site/locales.json` — supported URL codes and language-menu order.
- `site/assets/` — shared styles, scripts and artwork.
- `site/third-party-notices.txt` — published unchanged at `/third-party-notices.txt`.
- `scripts/build.py` — generates `_site/`, including `/`, all 31 `/<lang>/` pages, assets, robots and sitemap. Existing `_site/` content is replaced; generated files are not committed.

```sh
python3 -B -m unittest discover -s scripts -p 'test_*.py' -v
python3 scripts/build.py
python3 -m http.server 8769 --bind 127.0.0.1 --directory _site
```

Edit the template once for layout changes and update all 31 JSON files for new strings. `{{key}}` inserts an escaped translation; language links, alternate links and locale attributes are generated by the builder. Browser locale routing lives in `site/assets/language.js`.

Optional browser checks use Node.js and Playwright installed outside this repository. They run headlessly, verify all locale routes, language selection, root routing, mobile navigation, and the actual release downloads. With a baseline server, Korean/English full-page screenshots must match exactly at 1440 and 390 pixels in light and dark themes:

```sh
node scripts/test_browser.cjs http://127.0.0.1:8769
node scripts/test_browser.cjs http://127.0.0.1:8769 http://127.0.0.1:8768 /tmp/dolzip-site-shots
```

GitHub Pages uses **GitHub Actions**, configured in `.github/workflows/pages.yml`. Pull requests run the standard-library regression tests and build. Pushes to `main` additionally upload only `_site/` with `actions/upload-pages-artifact` and deploy with `actions/deploy-pages`. Repository Pages settings must use the workflow source:

```sh
gh api -X PUT repos/dolzip/dolzip.github.io/pages -f build_type=workflow
```
