# Dolzip for Mac

[홈페이지 / Website](https://dolzip.github.io) · [한국어](https://dolzip.github.io/ko/) · [English](https://dolzip.github.io/en/)

Mac을 위한 압축 도구입니다. 무료 풀기 앱 **DolUnzip**, 무료 명령줄 도구 **dz**, App Store 유료 전체 기능 앱 **Dolzip**을 준비하고 있습니다.

Archive tools for Mac: free **DolUnzip** for extraction, the free **dz** command-line tool, and paid **Dolzip** on the App Store.

## Download / 다운로드

[Download DolUnzip / dz (Free) · 다운로드 (무료)](https://github.com/dolzip/dolzip.github.io/releases/latest)

Dolzip — App Store: Coming soon / 곧 출시.

- **DolUnzip** — 무료 압축 풀기 전용 / Free extraction app (DMG): macOS 11+ · Apple Silicon · Intel.
- **dz** — 무료 명령줄 도구 / Free CLI (.pkg, `/usr/local/bin/dz`; Homebrew later): macOS 11+ · Apple Silicon · Intel.
- **Dolzip — App Store** — 유료 압축·풀기·미리보기·편집 / Paid create, extract, preview and edit: macOS 14+ · Apple Silicon · Intel.

[GitHub에서 소식 받기 / Watch for updates](https://github.com/dolzip/dolzip.github.io)
