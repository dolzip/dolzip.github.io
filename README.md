# Dolzip for Mac

[홈페이지 / Website](https://dolzip.github.io) · [한국어](https://dolzip.github.io/ko/) · [English](https://dolzip.github.io/en/)

Mac을 위한 압축 도구입니다. 무료 풀기 앱 **Dolzip Unpack**, 무료 명령줄 도구 **dz**, App Store 유료 전체 기능 앱 **Dolzip**을 준비하고 있습니다.

Archive tools for Mac: free **Dolzip Unpack** for extraction, the free **dz** command-line tool, and paid **Dolzip** on the App Store.

## Download / 다운로드

Coming soon / 곧 출시. macOS 14 or later, Apple Silicon.
Planned version: 0.1.0. Downloads will become available after Developer ID signing and Apple notarization; the first public stable release is planned as 1.0.0. No binaries or releases are published yet.

서명·공증 준비 전에는 바이너리를 배포하지 않습니다. 향후 무료 앱은 DMG 설치 파일로 제공합니다.
Use **Watch** on this repository to follow updates. This public repository hosts the website, issue tracker and future binary releases. It does not contain the application source code.
